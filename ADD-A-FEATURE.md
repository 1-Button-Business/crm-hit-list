# How to add a feature

You do not write code. You tell Claude what you want.

## The 3 steps

1. Open the Claude desktop app. Go to the Code tab. Choose this CRM's folder.
2. Type what you want in plain words. Or open your CRM, click "Add features" in the menu, and press "Copy message for Claude" on a card.
3. Press Enter. When Claude says it is done, refresh your CRM page.

## Things you can say

| You want | Say this |
|---|---|
| Different stages | "Change my stages to New, Consult booked, Client, Alumni." |
| A new box on each person | "Add a box for T-shirt size to every person." |
| A new ready-made message | "Add a ready message for checking in after a first session." |
| Your brand colors | "Make my CRM match my website: mysite.com" |
| A new screen | "Add a screen that shows everyone whose package ends this month." |
| A fix | "The birthday list is showing last month. Fix it." |
| An undo | "Undo the last change you made." |

## The bigger upgrades

These are on the "Add features" screen. Each has a step-by-step plan in the `recipes` folder that Claude follows.

| Upgrade | You need | Cost |
|---|---|---|
| Send real emails | Resend account, your own domain | Free to start |
| Send real texts | Twilio account, an approved number | A small fee per text |
| Use it on your phone | Convex and Cloudflare accounts | Free to start |
| Lead form for your website | Your CRM online first | Free |
| Morning briefing | Claude desktop app | Included |

The recipes are plans for Claude to follow, written and reviewed but not pre-built. Claude builds each one fresh in your copy and tests it with you.

## If something goes wrong

- Say: "That broke something. Put it back the way it was."
- Your client list is safe. It lives in the `data` folder, and a backup is saved every day you use the CRM.
- Still stuck? Bring it to the next 1BB call.

## Three habits that keep you safe

1. One change at a time. Look at it, then ask for the next.
2. Before a big upgrade, say: "Save a checkpoint first."
3. Never paste a password or key into the chat. Claude will tell you where to type it.
